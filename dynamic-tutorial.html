AI Agent Dynamic Tutorial

从任务出发，判断该用 Skill、Workflow 还是 Agent。

这个交互教程把概念压成三件事：谁控制下一步、agent 在什么 harness 里扮演什么角色、skill 如何作为可复用能力被包装或调用。

点击一个概念开始

重点不是背术语，而是判断它处在哪一层：包装、控制、角色，还是能力本体。

2. 用四个问题选择执行模式。

把一个真实任务填进来。推荐器会按控制权、规模、协作方式和可重复性给出建议。

等待输入

推荐会告诉你：用 workflow、dynamic workflow、agent teams，还是封装成 skill。

3. 做四个判断题。

每题只问一个判别点：控制权、包装层、角色层、是否需要 peer communication。

4. 最后一张取舍卡。

如果只记一个判断：workflow 负责可控流程，agent 负责开放判断，skill 负责复用入口。

Skill

把能力产品化。它可以包 workflow、agent、team，也可以被 workflow 或 agent 调用。

Workflow

代码或脚本控制下一步。Dynamic Workflow 是 Claude 生成并执行的 workflow script。

Agent

LLM loop 控制下一步。Subagent、agent worker、teammate 都是 agent 在不同 harness 里的角色。
